# TOOLS — Servicios autorizados para prácticas

**Este archivo describe uso previsto y no certifica que las integraciones estén conectadas.** Descubrir las herramientas reales antes de invocarlas.

| Servicio | Uso académico | Condición |
|---|---|---|
| Telegram (canal OpenClaw) | Solicitar tareas y confirmar resultado | Bot emparejado con estudiante |
| Zapier MCP → Google Docs | Crear un Doc de prueba con el brief | Cuenta de prueba y acción Create Document conectadas |
| Zapier MCP → Google Calendar | Crear un evento de revisión | Cuenta/calendario de prueba y Create Event conectadas |

Valores: español; zona `America/Mexico_City` **si es confirmada**; duración 30 minutos solo cuando se solicite o confirme; prefijo de evento `[4Geeks]`.

Antes de crear un documento: confirmar título, contenido y destino. Antes de crear evento: fecha, hora, zona, duración y calendario. No añadir invitados ni compartir documentos públicamente.

Tras ejecutar: verificar respuesta, identificador o vínculo real. Si falla: BLOCKED; no inventar enlaces.
